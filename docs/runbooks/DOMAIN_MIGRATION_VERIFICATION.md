Updated 2026-09-12. Primary dashboard: https://admin.promunch.in.

## Live configuration

- The new hostname is attached to the existing Vercel project. Old hostname remains active; no blanket redirects.
- Supabase Auth Site URL is https://admin.promunch.in. Redirect allowlist includes https://admin.promunch.in/auth/** and retains the old-host/local entries.
- Supabase authentication SMTP uses Resend, port 465, sender PROMUNCH CRM <hello@trypromunch.in>. Credentials are stored in Supabase, never in this document.
- Customer links, webhook destinations and worker schedules remain unchanged.

## Authentication fixes

Browser, server and middleware use identical cookie options: Secure in production, SameSite=Lax, Path=/, no Domain attribute. Existing cookies receive the new flags when rewritten during login or refresh.

Invitations generated by the admin API use a one-time token hash verified by the server callback. They do not depend on a browser PKCE verifier. The existing PKCE callback remains for magic links and password recovery. Login offers Forgot password, routing successful recovery to /auth/set-password. Callback destinations are restricted to local paths.

## Rollback

Keep both domains attached. Restore the previous production deployment if required; no data migration is involved. The old host's callbacks remain allowed. Reverting to a callback without token-hash support would break newly issued invitation links; preserve the callback handler or reissue only affected staff invitations deliberately.
