# B2B Leads v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild /dashboard/leads around saved lead lists, template-driven email sequences with a vertical-timeline builder, and an analytics tab (open/click/reply rates).

**Architecture:** New tables (`lead_lists`, `email_templates`, `email_sequences`, `email_sequence_steps`, `sequence_enrollments`) layer on the existing pipeline; every sequence send is inserted into `outreach_drafts` so Resend webhooks, replies, bounces, suppressions and history keep working unchanged. A new `processSequences()` stage joins the existing `tick()`; an hourly pg_cron job drives it.

**Tech Stack:** Next.js App Router API routes (requireSession), supabaseAdmin, Resend (`sendEmail`), OpenAI gpt-4o-mini (template variants + AI polish), vitest, pm- warm-editorial CSS.

## Global Constraints

- Brand copy: always "PROMUNCH" all caps; em dashes banned in all copy/prompts (memory: promunch-brand-copy-rules).
- Sender stays `outreach_settings.from_name <from_email>` (Parth), footer address appended via `bodyToHtml`.
- Daily cap counted on IST midnight boundary across ALL outreach sends (manual + sequence).
- Migrations: file in `promunch-email-agent/supabase/migrations/`, timestamp ≥ `20260706130000` (after pending wa_flow_settings), applied manually via dashboard SQL editor.
- Repo convention: commit directly to main; deploy only via `vercel --prod` (user-triggered).
- All new /api/leads/* routes gate with `requireSession()` from `src/lib/leads/auth`.
- Tests: vitest, `src/**/*.test.ts`, TZ pinned Asia/Kolkata.

Key DDL (complete file written in implementation):

```sql
create table if not exists lead_lists (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  description text,
  source_search_id uuid references lead_searches(id) on delete set null,
  archived boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create table if not exists lead_list_members (
  list_id uuid not null references lead_lists(id) on delete cascade,
  lead_id uuid not null references leads(id) on delete cascade,
  added_at timestamptz not null default now(),
  primary key (list_id, lead_id)
);
create table if not exists email_templates (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  subject text not null,
  body_text text not null,
  archived boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create table if not exists email_sequences (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  status text not null default 'draft' check (status in ('draft','active','paused','archived')),
  stop_on_reply boolean not null default true,
  ai_polish boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create table if not exists email_sequence_steps (
  id uuid primary key default gen_random_uuid(),
  sequence_id uuid not null references email_sequences(id) on delete cascade,
  position int not null,
  template_id uuid not null references email_templates(id),
  wait_days int not null default 0 check (wait_days >= 0),
  unique (sequence_id, position)
);
create table if not exists sequence_enrollments (
  id uuid primary key default gen_random_uuid(),
  sequence_id uuid not null references email_sequences(id) on delete cascade,
  lead_id uuid not null references leads(id) on delete cascade,
  contact_id uuid not null references lead_contacts(id),
  list_id uuid references lead_lists(id) on delete set null,
  status text not null default 'active'
    check (status in ('active','sending','completed','replied','bounced','stopped')),
  current_step int not null default 0,
  next_send_at timestamptz,
  last_sent_at timestamptz,
  error text,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  unique (sequence_id, lead_id)
);
create index if not exists seq_enroll_due_idx on sequence_enrollments (next_send_at) where status = 'active';
alter table outreach_drafts add column if not exists enrollment_id uuid references sequence_enrollments(id) on delete set null;
alter table outreach_drafts add column if not exists step_position int;
alter table outreach_settings add column if not exists send_window_start int not null default 9;
alter table outreach_settings add column if not exists send_window_end int not null default 18;
alter table lead_searches add column if not exists list_id uuid references lead_lists(id) on delete set null;
-- backfill: one list per existing search
insert into lead_lists (name, source_search_id, created_at)
  select initcap(category) || ' — ' || initcap(city), id, created_at from lead_searches
  on conflict do nothing;
update lead_searches s set list_id = l.id from lead_lists l where l.source_search_id = s.id and s.list_id is null;
insert into lead_list_members (list_id, lead_id, added_at)
  select s.list_id, ld.id, ld.created_at from leads ld join lead_searches s on s.id = ld.search_id
  where s.list_id is not null
  on conflict do nothing;
-- pg_cron hourly (Vault cron_secret, http_get because route is GET)
```

### Task 5: Sequence engine stage

**Files:**
- Create: `src/lib/leads/sequence-engine.ts`
- Modify: `src/lib/leads/engine.ts` (call stage in `tick()`, extend `TickSummary` with `sequenceSent: number`)
- Modify: `src/app/api/webhooks/resend-inbound/route.ts` (reply → stop enrollments for lead)
- Modify: `src/app/api/webhooks/resend/route.ts` (bounce → mark enrollment bounced via draft.enrollment_id)

**Produces:** `processSequences(summary): Promise<void>`:
1. Skip whole stage unless `inSendWindow` + not `settings.paused`.
2. Cap remaining = daily_cap − sentToday (IST); take up to `min(remaining, 5)` due enrollments (`status='active'`, `next_send_at <= now`, oldest first).
3. Atomic claim `active → sending` (compare-and-set like `claimLead`).
4. Load lead+contact+sequence+step+template; guards: lead.status in replied/bounced/suppressed → terminal status; contact suppressed → stopped.
5. `renderTemplate` subject+body; `sequence.ai_polish` → `polishOpening` (best-effort).
6. Insert `outreach_drafts` row (status 'sending', enrollment_id, step_position, model 'template'), send via `sendEmail` (same from/footer as manual route), mark draft sent + `outreach_events` 'sent' + lead 'contacted'.
7. Advance enrollment: last step → completed; else current_step+1, `next_send_at = nextSendAt(now, steps[next].wait_days, window_start)`, back to 'active'.
8. Send failure → draft 'failed', enrollment 'active' with error + retry next tick (next_send_at unchanged).
Stale 'sending' enrollments recovered in `recoverStaleClaims`.
