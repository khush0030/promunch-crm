How to use
Every prompt below is complete and ready to paste. Each one starts with the same
universe style block, so all characters come out looking like they belong in one film.
Generate in this order:

 1. Hero pose (2:3) for each character. Regenerate until the face and personality feel right.
 2. Lock it. Save the approved image. From now on, attach it as reference image #1 and
    start every prompt with "Keep this exact character identical."
 3. Model sheet + expression sheet (16:9) using the templates at the end.
 4. Scale lineup of all five together, so sizes stay the same in every episode.

For Makhana and Peanut, attach your current images as the reference and use the
prompts as edit instructions. They're already close.

Universe style block (already inside every prompt; shown here for reference):

  Premium 3D animated feature-film character design, stylised and highly
  expressive, tactile realistic food textures with soft subsurface scattering,
  cinematic studio lighting with a warm key light and soft rim light, seamless
  warm-grey studio background, full body, centred. Exaggerated cartoon
  proportions with strong squash-and-stretch appeal and a bold, readable
  silhouette. The comedy is in the acting: the face and pose instantly tell you
  who this character is. Premium and polished, not childish, not creepy.

everyone else is loud and dramatic, and he just doesn't care. Both forms share the same
face, so viewers instantly know it's him.

Model sheets and lineup
Run these only after a hero image is approved. Attach it as reference image #1 every time.

Turnaround sheet (one per character)

  Keep this exact character identical to the reference image: same face,
  proportions, colours, textures, costume and accessories. Create a
  professional 3D animation character model sheet on a seamless warm-grey
  background: four full-body views in a row at the same scale and height (front
  view, three-quarter view, side profile, back view), neutral standing pose,
  arms slightly away from the body, even studio lighting, no shadows
  overlapping. Aspect ratio 16:9. No text, labels, numbers, watermarks or
  lettering anywhere in the image.


Expression sheet (one per character)

  Keep this exact character identical to the reference image. Create a
  character expression sheet on a seamless warm-grey background: a 3 x 2 grid
  of head-and-shoulders close-ups, same angle and lighting in each, showing six
  exaggerated cartoon expressions: smug, shocked, furious, laughing hard,
  defeated and sulking, scheming. Keep the face design, colours and accessories
  identical in every panel. Aspect ratio 16:9. No text, labels, watermarks or
  lettering anywhere in the image.

Flags before production
     Protein claim doesn't match the packs. The script says "up to 45 g protein per 100 g",
     but the approved pack badges are 46g (Himalayan Rock Salt) and 42g (Indori Chatka
     and Masala Mania). The Episode 3 on-screen line needs to change to match the label.
     Don't put any protein number inside the generated images.
     Brand colours. The PROMUNCH palette is maroon, cyan blue, sunny yellow and orange,
     not bright red. Edamame's armour uses maroon and gold to stay on-brand.
     Keep rivals generic. No logos, brand names or recognisable pack designs on Makhana,
     Peanut, Chips or Bar. Chips is the one to watch: that's why he moved from blue to
     chrome and magenta.
     PROMUNCH pack. Whenever the pouch appears (Peanut's Episode 3 scene, the
     coronation, the end frame), attach the real pack render as a reference. Don't let the
     model invent the label.
